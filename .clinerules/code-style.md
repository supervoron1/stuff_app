# Стиль кода

## TypeScript / React

- **Строгий режим**: `tsconfig.json` включает `strict: true` — не использовать `any`, не подавлять ошибки через `@ts-ignore`/`@ts-expect-error` без обоснования.
- Именование:
  - файлы/папки — `kebab-case` (`use-inventory.ts`, `stock-indicator.tsx`);
  - функции/переменные — `camelCase`; типы/интерфейсы — `PascalCase`;
  - хуки — с префиксом `use-` в имени файла (`hooks/use-inventory.ts`).
- Компоненты — function declarations или arrow с явным типом пропсов (интерфейс `Props` рядом с компонентом).
- Не использовать default export для React-компонентов в этом проекте (проверь конвенцию в существующих файлах). **Исключение** — спец-файлы App Router (`app/page.tsx`, `app/layout.tsx`, `app/manifest.ts` и т.п.): там default export обязателен по конвенции Next.js.
- Импорты: `@/*` алиас для корня проекта (настроен в `tsconfig.json`).

## Форматирование

- Без лишних переносов строк и пустых блоков.
- Следуй стилю существующего кода: он задаёт источник истины.

## React-специфика

- Клиентские компоненты — директивы `"use client"` только там, где нужны хуки/события.
- Не тащить серверный код (Prisma, Supabase-клиент с секретами) в клиентские компоненты.
- Статусы наличия товара — только из набора в `lib/constants.ts` (`SUFFICIENT | LOW | OUT`).
