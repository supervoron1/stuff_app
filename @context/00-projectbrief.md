# Project Brief — «Запасы»

## Назначение
Мобильное PWA-приложение для учёта запасов по категориям. Категории → товары → статус наличия. Синхронизация между несколькими устройствами, работа в офлайне.

## Ключевые требования
- Товары разбиты по категориям (CRUD для обоих)
- Наличие: 4 состояния — 🟢 есть (`SUFFICIENT`), 🟡 мало (`LOW`), 🔴 нет (`OUT`), 🔴 «!» критично (`CRITICAL`)
- Тап по цветному индикатору циклично меняет статус (SUFFICIENT → LOW → OUT → CRITICAL → SUFFICIENT); быстрые тапы обрабатываются корректно (оптимистично); CRITICAL — красный «!» вместо галочки
- **Порядок товаров и категорий**: перетаскивание (drag-n-drop) — товары внутри категории за ручку ⠿ + название, категории за заголовок; порядок сохраняется и синхронизируется
- Использование с мобильных устройств через браузер (PWA, установка на главный экран)
- **Обновление PWA** «как в Play Market»: баннер «Доступна новая версия» + обновление в один тап (версионирование кэша SW)
- **Тёмная и светлая тема**: переключатель ☀️/🌙/🖥 (светлая/тёмная/системная), выбор локальный на устройстве
- Данные актуальны на всех устройствах (единая БД + синхронизация)
- Работа без интернета (офлайн-режим + очереди синхронизации)
- Имя пользователя для аудита действий (без пароля/авторизации)
- Фото товаров — опционально
- Конфликты: last-write-wins (побеждает поздняя запись по `updatedAt`)

## Сокращённая сводка (для быстрого входа в контекст)
- **Стек**: Next.js 16 (App Router) + React 19 + TypeScript + Tailwind 4 + Prisma 7 + PostgreSQL (Neon) + Supabase Storage + Dexie (IndexedDB) + @dnd-kit (drag-n-drop)
- **БД**: Neon (IPv4). Изначально пытались Supabase, но его direct-хост работает только по IPv6 на бесплатном тарифе → перешли на Neon
- **Офлайн**: Dexie (IndexedDB) → локальный кэш `categories`/`products` + очередь `outbox`; push на `/api/sync` при появлении сети (outbox pattern)
- **Оптимистичный UI**: смена статуса и перетаскивание обновляют интерфейс мгновенно; синхронизация в фоне с debounce
- **Аудит**: таблица `AuditLog` + имя пользователя из localStorage
- **Тема**: `hooks/use-theme.ts` (light/dark/system), localStorage, class-based dark mode, анти-flash
- **Обновление PWA**: версия кэша в `sw.js`, периодическая проверка (60 сек), баннер «Доступна новая версия»
- **Деплой**: Vercel (рекомендуется). Переменные окружения см. `README.md`
