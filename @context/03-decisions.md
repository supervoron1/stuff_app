# Ключевые решения (Decision Log)

Здесь собраны решения, принятые при разработке, и их обоснование. Это позволит не повторять анализ при новых вопросах.

## D1. Стек: Next.js 16 + React 19 + TypeScript + Tailwind 4
**Решение:** Next.js 16 (App Router), React 19, TypeScript (strict), Tailwind CSS 4.
**Почему:** единая платформа (UI + API + деплой на Vercel), современный App Router, Server Actions для мутаций, мобильный UI на Tailwind.

## D2. Офлайн-синхронизация: outbox pattern на Dexie (IndexedDB)
**Решение:** локальный кэш `categories`/`products` + очередь `outbox` в IndexedDB (Dexie); при появлении сети — push очереди на сервер, затем полный снимок (pull).
**Почему:** нужна работа без интернета; outbox гарантирует, что офлайн-изменения не потеряются и будут отправлены при первой возможности.
**Детали:** ID генерируются на клиенте (uuid) — без этого нельзя создавать записи офлайн и потом синхронизировать.

## D3. Конфликты: last-write-wins по `updatedAt`
**Решение:** при одновременном изменении с двух устройств побеждает запись с более поздним `updatedAt` (товар) / `createdAt` (операция очереди).
**Почему:** просто и предсказуемо для небольшого объёма данных (≤200 товаров), согласовано с пользователем.

## D4. База данных: Neon (PostgreSQL) вместо Supabase
**Проблема:** Supabase на бесплатном тарифе — direct-подключение к БД **только по IPv6** (порт 5432 недоступен с IPv4-сети пользователя); connection pooler для проекта не был включён → ошибка `P1001` / `tenant not found`.
**Решение:** основная БД — **Neon** (бесплатный PostgreSQL, работает по IPv4, совместим с Prisma и Vercel). Supabase оставлен **только для фото** (его API доступен по IPv4).
**Почему:** минимальные правки кода (только `DATABASE_URL`), мгновенная работоспособность из локальной сети и на Vercel.

## D5. Фото: Supabase Storage (bucket `products`, public)
**Решение:** загрузка фото через `POST /api/upload` → Supabase Storage; bucket создаётся автоматически при первой загрузке.
**Почему:** не хочется хранить файлы в БД; Supabase Storage бесплатен и уже используется в проекте.
**Ограничение:** загрузка/замена фото — **только онлайн** (офлайн-загрузку не реализуем — файлы всё равно нужно передать на сервер).

## D6. Аудит: простое логирование с именем пользователя
**Решение:** таблица `AuditLog (action, entity, entityId, oldValue, newValue, userName, createdAt)`; имя пользователя запрашивается в UI и хранится в localStorage.
**Почему:** по ТЗ нужна авторизация без пароля — только фиксация «кто и что менял».

## D7. Оптимизация производительности на Vercel (важная находка)
**Проблема:** тап по индикатору занимал несколько секунд на Vercel (локально мгновенно).
**Причина:** до **3 последовательных сетевых запросов** к Serverless-функции `/api/sync` (POST push → GET pull → GET в `syncNow`) + **«холодный старт»** Lambda-контейнера на бесплатном тарифе; кнопка блокировалась через `await`.
**Решение:**
1. `cycleStatus` → **оптимистичный отклик**: запись в IndexedDB + мгновенное обновление UI; синхронизация в фоне (без блокировки).
2. `POST /api/sync` → применяет операции **и возвращает свежий снимок** в том же ответе (1 запрос вместо 3).
3. `syncNow` при пустой очереди делает 1 GET.
**Рекомендация пользователю:** ставить функции в регион, близкий к БД; при желании — настроить Incognito-миграцию хостинга.

## D8. PWA: манифест + Service Worker
**Решение:** `app/manifest.ts` + `public/sw.js` (кэш app shell, network-first для API) + иконки (`scripts/generate-icons.mjs`).
**Почему:** установка на главный экран, офлайн-открытие, полноэкранный режим.

## D9. Удаление диагностических скриптов
**Решение:** удалены `scripts/find-pooler.mjs` и `scripts/test-connection.mjs` (содержали пароль БД в открытом виде), убрана dev-зависимость `pg`.
**Почему:** временная диагностика подключения; риск утечки секрета.

## D10. Memory Bank (этот файл)
**Решение:** документировать архитектуру/структуру/решения в `CLAUDE.md + @context/*.md`, чтобы будущие сессии Cline быстро восстанавливали контекст.
**Почему:** идеология Cline — «read file по требованию»; короткий `CLAUDE.md` всегда в контексте, детали грузятся по ссылке.
