## ⚠️ Известные ограничения

- **Фото**: загрузка/замена — только онлайн; офлайн-загрузка не реализована (файлы всё равно нужны на сервере).
- **Supabase / Neon**: для фото используется Supabase Storage; БД — Neon (по причине D4).
- **Холодный старт Vercel**: на бесплатном тарифе первые запросы после простоя могут быть медленными (Serverless); UI уже оптимизирован на мгновенный отклик.
- **Фильтрация + поиск**: при активных поиске и фильтре по статусу категория скрывается, даже если в ней есть товары нужного статуса, но не совпадающие с запросом (консистентно, но может удивить).
