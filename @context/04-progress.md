## ⚠️ Известные ограничения

- **Фото**: загрузка/замена — только онлайн; офлайн-загрузка не реализована (файлы всё равно нужны на сервере).
- **Supabase**: БД — пулер Supavisor session mode (IPv4, см. D27); фото — Supabase Storage.
- **Холодный старт Vercel**: на бесплатном тарифе первые запросы после простоя могут быть медленными (Serverless); UI уже оптимизирован на мгновенный отклик.
- **Поиск/фильтры**: категории без совпадений скрываются (осознанное поведение, см. D18); при «Все» без поиска пустые категории остаются видимыми.
- **Обновление PWA**: происходит только при открытом приложении; на iOS Safari `registration.update()` в standalone-PWA может игнорироваться.
- **Манифест PWA статичен**: splash screen/метаданные установленного приложения остаются светлыми (ограничение, см. D19).
- **Тема локальная**: выбор темы хранится на устройстве (localStorage), не синхронизируется между устройствами.
