# Справочник Emoji для коммитов (Gitmoji & Conventional Commits)

| Сфера применения | Описание изменения | Иконка | Код для коммита |
| :--- | :--- | :---: | :--- |
| **Ребрендинг и Имена** | Изменение названия, текстовых наименований, брендинга | 🏷️ | `:label:` |
| | Переименование папок, файлов или перенос путей | 🚚 | `:truck:` |
| | Изменение метаданных, имен модулей и общей информации | 📇 | `:card_index:` |
| **Основные типы** | Новый функционал (`feat`) | ✨ | `:sparkles:` |
| | Исправление багов (`fix`) | 🐛 | `:bug:` |
| | Документация (`docs`) | 📝 | `:memo:` |
| | Обновление крупных документов (руководства, вики) | 📚 | `:books:` |
| | Рефакторинг кода (`refactor`) | 🔨 | `:hammer:` |
| | Стилизация, форматирование, дизайн (`style`) | 🎨 | `:art:` |
| | Повышение производительности (`perf`) | ⚡ | `:zap:` |
| **Инфраструктура** | Конфигурация, рутинные задачи (`chore`) | 🔧 | `:wrench:` |
| | Сборка, внешние пакеты (`build`) | 📦 | `:package:` |
| | Настройка непрерывной интеграции (`ci`) | 👷 | `:construction_worker:` |
| | Исправление сборки CI | 💚 | `:green_heart:` |
| **Зависимости** | Обновление версий зависимостей (`dependencies`) | ⬆️ | `:arrow_up:` |
| | Понижение версий зависимостей | ⬇️ | `:arrow_down:` |
| **Тесты и Качество** | Добавление или обновление тестов (`test`) | ✅ | `:white_check_mark:` |
| | Исправление упавших тестов | 🚨 | `:rotating_light:` |
| **Критические правки** | Срочное исправление на продакшене (Hotfix) | 🚑 | `:ambulance:` |
| | Исправление уязвимостей (Security) | 🔒 | `:lock:` |
| | Удаление кода или неиспользуемых файлов | 🔥 | `:fire:` |
| | Работа в процессе (Work in progress) | 🚧 | `:construction:` |
| **Релизы** | Первый коммит / Инициализация проекта | 🎉 | `:tada:` |
| | Выпуск новой версии / Релизный тег | 🔖 | `:bookmark:` |
| | Развертывание (Deploy) приложения | 🚀 | `:rocket:` |

## Пример использования в терминале
```bash
git commit -m ":label: Переименовано приложение из AppOld в AppNew"
```
